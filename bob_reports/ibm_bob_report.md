# IBM Bob Development Report: MenuNest

## Project

MenuNest: AI Copilot for Food Entrepreneurs

## Hackathon Focus

This project demonstrates how IBM Bob can help a developer move from an idea to a working software prototype during a hackathon.

## How IBM Bob Helped

IBM Bob supported:

- Product workflow design
- MVP feature selection
- Repository structure planning
- Streamlit app implementation
- Prompt and JSON schema design
- Demo fallback data strategy
- UI styling and polish
- Test creation
- README and documentation
- Submission preparation

## Demo Reliability

The app uses stable demo generation by default to avoid API-key or network issues during judging.
